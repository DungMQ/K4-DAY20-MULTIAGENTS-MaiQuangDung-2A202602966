---
name: adhere-to-docstring-specifications
description: When implementing functions, ensure that the behavior aligns with the specifications outlined in the docstrings.
---
- Read the docstring of each function carefully before implementation.
- Identify all parameters and return values specified in the docstring.
- Implement the function logic to match the expected behavior described.
- Write unit tests that validate the function against its docstring specifications.
- Review and update the docstring if the implementation changes the expected behavior.
- Ensure that edge cases and error handling are considered as per the docstring.
