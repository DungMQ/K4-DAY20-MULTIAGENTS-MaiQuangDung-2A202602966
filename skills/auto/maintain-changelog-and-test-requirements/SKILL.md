---
name: maintain-changelog-and-test-requirements
description: When fixing bugs or making changes, ensure that all modifications are documented and tested as required.
---
- Create a CHANGELOG.md entry for each fix or feature added, following the specified format.
- Ensure that each bug fix is accompanied by a regression test in a dedicated test file.
- Verify that the test file passes successfully after modifications.
- Document the purpose of each test clearly to facilitate understanding.
- Regularly review the changelog and test files to ensure they are up-to-date with the latest changes.
- Use consistent formatting and language in the changelog for clarity.
